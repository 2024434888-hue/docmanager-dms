# DocManager - Document Management System

DocManager is a localhost web-based Document Management System developed using PHP and MySQL/MariaDB. It allows users to upload, view, and download documents, while administrators can manage users, account requests, password-reset requests, document categories, and activity records.

## Technologies Used

- PHP
- HTML
- CSS
- MySQL/MariaDB
- phpMyAdmin
- XAMPP

## Main Features

### Regular User
- Log in and log out
- View dashboard
- Upload documents
- View documents
- Download documents
- Request an account
- Submit a forgot-password request

### Administrator
- Create user accounts
- Assign user roles
- Approve account requests
- Process password-reset requests
- Manage document categories
- Delete documents
- View activity logs
